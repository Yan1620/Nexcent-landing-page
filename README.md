## English

### 📝 Project Description
A modern, fully responsive landing page built with clean HTML and CSS (using Grid and Flexbox). The layout perfectly adapts to all screen sizes, from mobile phones to large desktop monitors.

### 🚀 Live Demo
You can view the live project here: **[https://yan1620.github.io/Nexcent-landing-page/]**

### 🛠️ Technologies Used
* HTML5 (Semantic tags)
* CSS3 (BEM methodology, Flexbox, CSS Grid)
* Mobile-first approach

## Русский

### 📝 Описание проекта
Современный и полностью адаптивный лендинг, сверстанный на чистом HTML и CSS с использованием CSS Grid и Flexbox. Макет идеально подстраивается под любые экраны: от мобильных телефонов до больших мониторов.

### 🚀 Демо-версия
Посмотреть работающий сайт можно по ссылке: **[https://yan1620.github.io/Nexcent-landing-page/]**

### 🛠️ Использованные технологии
* HTML5 (Семантическая верстка)
* CSS3 (Методология БЭМ, Flexbox, CSS Grid)
* Подход Mobile-first (адаптивность под телефоны)
